## 1. 我的投资体系（执行纪律）

### 1.1 买入纪律（原文抽象成动作）
- 核心：买得便宜，按 **6.5/6/5/4 折**分批买入
- 6.5折开始：先买计划仓位的 **1/3**
- 剩余 2/3 分 5 份：后续每下跌 **5%** 买入 1 份
- **跌破 4 折停止加仓**，触发基本面复核

### 1.2 卖出纪律（金顶战法）
- 只有当仓位达到计划仓位 **70%** 以上，才启动“固定市值卖出”
- 固定市值卖出：
  - 以某一时点“底仓市值”为基准
  - 市值每上涨 **5000**（可按资金规模调整）卖出 **5000**，保持底仓市值不变
- 分段减仓备选：
  - 上涨 20% → 减仓 1/4
  - 再涨 20% → 再减 1/4
  - 再涨 20% → 再减 1/4
  - 留 1/4 底仓长期持有
- 没买够：只买不卖，除非“暴涨严重高估”（需用估值锚点判断）

### 1.3 硬止损（任意触发直接清仓）
- 公司业绩暴雷、连续亏损
- 商业模式 / 护城河逻辑破坏
- 行业逻辑彻底反转（不是周期波动，而是需求结构性萎缩）
- 财务造假嫌疑 / 大股东重大风险

## 2. 好赛道（行业与周期）

### 2.1 行业画像（工程机械的“周期因子”）
工程机械典型是“需求弹性大、库存与价格战放大波动”的周期行业。重点跟踪：
- 需求端：基建投资、地产开工、制造业投资、设备更新政策
- 开工端：开工小时数（比销量更贴近真实需求）
- 渠道端：经销商库存、回款情况（下行期风险会集中在这里）
- 供给端：行业价格战、产能投放、竞争对手策略
- 海外端：出口订单、区域景气、汇率与贸易环境

### 2.2 需要你每季更新的“证据表”（可截图/记录）
- 国内挖机销量：当前值 vs 近5-10年区间（低/中/高位）
- 开工小时数：当前 vs 历史区间
- 渠道库存：高/中/低（可用公开口径或公司/研报描述）
- 价格战：是否加剧（公开信息/毛利率趋势/行业口径）
- 海外：出口占比趋势、主要区域增速是否回落

## 3. 好公司（商业模式 / 竞争力 / 盈利能力）

### 3.1 商业模式要点（需要被验证的假设）
- 产品矩阵：挖机、起重、混凝土机械等（周期波动不同）
- 护城河可能来自：
  - 规模成本优势
  - 品牌与渠道网络（经销商+服务）
  - 产品可靠性与交付能力
  - 海外渠道与本地化（若出口成为关键增量）

你要给出“证据”回答：
- 份额：核心品类份额是上升/稳定/下降？
- 定价：毛利率波动主要来自周期，还是竞争恶化（价格战）？
- 海外：增长是“能力驱动”还是“景气+低基数”？

### 3.2 盈利质量与财务风险（强周期重点）
强周期标的容易出现“利润看起来行，但现金流很差”的情况，需要重点审：
- 经营现金流（CFO）与利润的匹配：是否长期背离？
- 应收账款：是否快速上升、周转变慢（回款风险）
- 存货：是否积压、周转变慢（需求下滑/价格战信号）
- 有息负债与现金：下行期能否扛得住？

## 4. 好价格（主估值法 + 买点锚定）

> 原则：先分类，再定“主估值法 + 校验法”，不为想买而挑最便宜口径。

### 4.1 主估值法：周期中枢利润 × 合理PE（Normalized PE）
- 一句话公式：**MV_base ≈ NP_mid × PE_mid**
- 适用原因：工程机械盈利随周期波动大，用“中枢利润”比用 TTM 更能避免在顶/底误判。

#### 第一步：准备输入数据（统一口径）
- 近 10 年归母净利润（2016–2025，亿元）：
  - 2016：0.20
  - 2017：20.92
  - 2018：61.16
  - 2019：113.26
  - 2020：154.35（周期峰值）
  - 2021：120.33
  - 2022：42.90（周期底部）
  - 2023：45.27
  - 2024：59.75
  - 2025：71.36（前三季度；全年预计约 90–95）
- 总股本（亿股）：91.95
- 最新股价（截至 2026-03-20 收盘）：19.43 元
- 当前市值（亿元）：19.43 × 91.95 ≈ 1786.59

#### 第二步：计算周期中枢利润 NP_mid
- 选定“景气中段”连续 3 年均值（并固定，不临时换年份）
  - 选定年份：2018、2019、2021
  - 理由：
    - 2018：周期启动、盈利大幅回升
    - 2019：景气中段、盈利稳定高位
    - 2021：景气后半段、仍处高盈利
  - 剔除：2016/2017（底部微利）、2020（顶部）、2022/2023（下行底部）
- NP_mid（三年归母净利润均值，亿元）= (61.16 + 113.26 + 120.33) / 3 = **98.25 亿元**

#### 第三步：选择合理 PE_mid（写死，不临时调高）
- 用“景气中段的估值”来代表合理倍数（严格按你在《估值体系》的规则）
  - 选定年份：2018、2019、2021
  - 同期年度平均 PE-TTM：24.24、14.25、15.00
  - PE_imp 均值 = (24.24 + 14.25 + 15.00) / 3 = **17.83 倍**
- 你最终写死：PE_mid = **18 倍**

补充说明（避免把 PE-TTM 当成“合理倍数”）：
- 这里的 PE_mid 指的是“对 NP_mid 的估值倍数”（Normalized PE），不是某一年的 PE-TTM
- 周期底部/微利年 PE-TTM 往往会非常高（分母太小），用它决定 PE_mid 会失真
- 复核方式：用 PE_imp = 当年平均市值 / NP_mid 反推（或用年度平均 PE-TTM 做参考），在“景气中段/正常年份”（剔除顶/底）取中位数/均值后写死
- 以当前数据复核：PE_imp（当前市值/NP_mid）= 1786.59 / 98.25 = **18.18 倍**，与写死的 PE_mid≈18 倍一致

#### 第四步：算基准合理市值与基准合理股价
- MV_base = NP_mid × PE_mid = 98.25 × 18 = **1768.50 亿元**
- Price_base = MV_base / 总股本 = 1768.50 / 91.95 = **19.23 元**

#### 第五步：映射 6.5/6/5/4 折买点（可直接下单的锚点）
- 6.5折启动：Price_65 = 19.23 × 0.65 = **12.50 元**
- 6折加仓：Price_60 = 19.23 × 0.60 = **11.54 元**
- 5折加仓：Price_50 = 19.23 × 0.50 = **9.62 元**
- 4折停止：Price_40 = 19.23 × 0.40 = **7.69 元**

#### 第六步：用“几折”做动作判断
- 当前价格 / 基准合理价 = 19.43 / 19.23 = **1.01 倍**
- 若现价 ≤ Price_65：允许启动建仓（买入计划仓位的 1/3）
- 若继续下跌触发 0.60 / 0.50 / 0.40：按分批规则加仓
- 若跌破 Price_40：停止加仓，进入“基本面复核清单”

## 8. 风险清单（必须写出来）

### 8.1 周期风险
- 地产/基建周期超预期下行，需求长期走弱

### 8.2 财务与现金流风险
- 回款变差（应收飙升/周转恶化）导致现金流承压
- 存货积压导致减值或价格压力

### 8.3 海外风险
- 出口景气回落、汇率与贸易环境变化
- 海外渠道能力不及预期（增长不可持续）
